# BoardRaid Releases
这是 BoardRaid **正式客户端 JAR 发布仓库**。请到 [Releases](https://github.com/BoardraidDev/releases/releases) 下载对应版本的 jar 与 SHA256SUMS.txt。
最新正式版：**0.5.5**。历史文件保留原始二进制，不用重新编译的包冒充原发布物。
## 版本清单
[versions.json](versions.json) 记录已核验文件的内部版本、大小、SHA-256 和下载链接；unavailable 单独记录尚未找回可靠正式产物的版本。
未找回的版本不创建空发布、不上传开发构建。历史文件不代表仍能连接当前服务器；游玩请使用最新正式版。
