## 正式版本策略
体验服在 release 验证，人工通过后由维护者晋升 master；从 master 的验证产物发布正式版。
正式版语义版本采用 MAJOR.MINOR.PATCH：不兼容变化、兼容功能、兼容修复分别升级对应段；游戏匹配兼容性另有协议版本，不能仅凭文件名判断互通。
版本一经发布不替换同版本文件。更新需核验 JAR 内版本、发布清单的文件大小和 SHA-256、正式客户端要求及既有发布闸门。新版本由维护者显式发布，不由文档 PR 自动触发。
## 下载边界
本仓库不托管 Minecraft 游戏文件、账号信息或整合包二进制；也不为未核验旧版本填造哈希。没有创建 GitHub Release 不代表官网下载不可用。
Wiki 内容更新与游戏版本发布独立。请先阅读 [Wiki](https://github.com/BoardraidDev/wiki)。
