# BoardRaid Releases
这是 BoardRaid **正式客户端 JAR 发布仓库**。请到 [Releases](https://github.com/BoardraidDev/releases/releases) 下载对应版本的 jar 与 SHA256SUMS.txt。
最新正式版：**0.5.5**。历史文件保留原始二进制，不用重新编译的包冒充原发布物。
## 版本清单
[versions.json](versions.json) 记录已核验文件的内部版本、大小、SHA-256 和下载链接；unavailable 单独记录尚未找回可靠正式产物的版本。
未找回的版本不创建空发布、不上传开发构建。历史文件不代表仍能连接当前服务器；游玩请使用最新正式版。
## 社区与发布权限
社区可直接向本仓库 master 提 PR，更正文档或报告历史文件缺失，由项目所有者审核。不要求走私人仓库的 release/体验服分支流程。
正式 JAR 由项目所有者核验后通过 GitHub Releases 发布，不接受 PR 随意替换二进制。文档 PR 合并不会自动部署服务器或改变官网的自动更新清单。
发布前检查包内版本、正式标记、生产映射和校验和。已发布版本不覆盖同名资产；发现问题由维护者说明并处理。
GitHub 标签标记本仓库的发布元数据，不提供私人游戏源码。不得重新分发账号资料、Minecraft 游戏文件或服务端密钥。
